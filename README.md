# 📂 Workshop de Genômica de Populações
Bem-vindo ao repositório central do nosso workshop! Este espaço contém o roteiro da práctica e os código para realizar o fluxo completo de análise de variantes genéticas.

## 🎯 Objetivos do curso
* Dominar a linha de comando **Linux** voltada para genômica.
* Realizar o demultiplex da biblioteca e o controle de qualidade (QC)
* Identificar os artefactos da técnica da biblioteca e realizar a triagem das secuencias. 
* Realizar o mapiamento de sequências contra o genoma de referência e comparar diferentes arquivos de mapameanto (SAM/BAM/CRAM).
* Executar a chamada de variantes (**Variant Calling**) utilizando abordagens baseadas em bases e haplótipos.
* Filtrar e normalizar arquivos **VCF**.
